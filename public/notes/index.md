# Robotics notes — Reachy Mini & Microduck

Companion notes for the interactive **Robot Explorer** tutorial.

## Open the 3D app

From the project root:

```bash
pnpm install
pnpm dev
```

Open the local Vite URL, then click **Tutorial** in the footer.

Each lesson’s **Learn more** link opens the matching note below.
